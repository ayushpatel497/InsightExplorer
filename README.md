# InsightExplorer 📊

*Comprehensive Data Analytics Project*

---

## 📝 Project Overview

InsightExplorer is a data analytics project designed to showcase advanced data handling and querying skills. Using seven datasets sourced from Kaggle, this project demonstrates how to effectively transform raw data into meaningful insights by leveraging MySQL for database management and analytics.

---

## 🚀 Features

- *Data Integration*: Combined data from seven distinct Kaggle datasets into MySQL tables.
- *Complex Queries*: Performed advanced SQL queries, including joins, filtering, grouping, and aggregations.
- *Insights Generation*: Extracted actionable insights and presented key findings.
- *Data Normalization*: Ensured data quality through normalization techniques.

---

## 🛠 Technologies Used

- *Database*: MySQL
- *Data Source*: Kaggle Datasets
- *Tools*: Command-Line Interface (CLI)

---

## 📦 Installation & Setup

1. *Clone the Repository:*
   bash
   git clone https://github.com/ayushpatel497/InsightExplorer.git
   cd InsightExplorer
   

2. *Set Up the Database:*
   - Import the provided .sql dump file into your MySQL server.
   - Use the command:
     bash
     mysql -u your_username -p < database_dump.sql
     

3. *Verify Data Import:*
   - Open MySQL Workbench or CLI and ensure all tables are loaded correctly.

4. *Run Queries:*
   - Use the provided queries.sql file to execute pre-defined queries.
